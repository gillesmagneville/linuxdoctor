Explanation

The page cache holds 67.9 GB (27.4% of RAM): copies of files recently read or written, kept so the next access is served from memory instead of the disk. Disk-block buffers add 1.3 GB.

63.7 GB of the file cache has not been touched recently (the kernel drops that first) and 5.5 GB is in active use. Running programs map 2.0 GB of it.

Reclaimable kernel caches (the dentry and inode caches that remember file names and metadata) add 3.1 GB.

This memory is not wasted: it makes file access fast and is handed back to programs the moment they ask for it.

A large cache is therefore a sign of a healthy machine, not a leak. Emptying it (echo 3 > /proc/sys/vm/drop_caches) frees nothing of lasting value: it only forces files to be read from the disk again and slows everything down until the cache is rebuilt. It is a benchmarking tool, not an optimisation.

ZFS keeps its own cache (the ARC) outside the page cache; it is described under Kernel memory.

✓ INFO MEM010 Swap Configuration Swap

Confidence 100% (direct observation)

Evidence

swap_typenone
swap_total_kb0
swap_devices0
zswap_enabledfalse

Explanation

Swap: none configured.

No swap is configured. Without it the kernel can only reclaim file cache; once that is gone, the only option left is the OOM killer. Even a small swap lets idle program memory move out of the way and gives a memory spike somewhere to go. (Exceptions: Kubernetes nodes, where the kubelet expects swap off by default, and appliances that deliberately prefer an OOM kill to slowness.)

Recommendation

  1. Preferred: compressed RAM swap (zram). It needs no disk space, causes no disk wear and is much faster than swap on a disk. This sets it to half of RAM, kept after reboot:
    sudo apt install systemd-zram-generator     # Fedora, Arch, openSUSE: zram-generator
printf '[zram0]\nzram-size = ram / 2\ncompression-algorithm = zstd\n' | sudo tee /etc/systemd/zram-generator.conf
sudo systemctl daemon-reload
sudo systemctl start systemd-zram-setup@zram0.service
  2. Or a swap file of 8 GB on disk (ext4 or xfs; on Btrfs use 'btrfs filesystem mkswapfile' instead of fallocate):
    sudo fallocate -l 8G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab   # keep it after reboot
